# Авторизация App - Тестирование (Лабораторная работа 9)

## Description
Данный проект представляет собой приложение с реализацией интерфейса авторизации и регистрации пользователя. Приложение использует `UserDefaults` и локальные `.plist` файлы для хранения данных. В рамках лабораторной работы проект был покрыт Unit и UI тестами с использованием фреймворка XCTest, а также настроена непрерывная интеграция (CI/CD) через GitHub Actions.

## Installation
1. Клонируйте репозиторий: 
2. Откройте проект в Xcode 14+.
3. Дождитесь индексации проекта.

## Usage
- Для запуска приложения выберите симулятор (например, iPhone 14) и нажмите `Cmd + R`.
- Для запуска Unit и UI тестов перейдите во вкладку Test Navigator в Xcode и нажмите кнопку Play напротив `example1_2.xctestplan`, либо используйте шорткат `Cmd + U`.
